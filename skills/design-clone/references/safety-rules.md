# 安全规则（safety-rules）

设计克隆会真实操作设备/浏览器，必须遵守以下红线。冲突时安全 > 任务完成度。

## 1. 支付红线（最高优先级）

**任何"确认支付/付款/转账/下单/充值"的最终确认动作，永远不自动执行。**

- 允许：进入支付流程、查看订单/收银台页面、截图记录
- 到达确认页：截图 → 记录边 `"blocked_by": "safety:payment"` → 停止该路径，向用户汇报
- 识别信号：文案含 支付/付款/转账/充值/下单/确认购买/¥金额+确认 等；密码键盘弹出

## 2. 凭证红线

- **不输入任何密码、短信/邮箱验证码、不完成人脸/指纹验证**
- 遇到登录：
  - Web：切换可见浏览器窗口，请用户手动登录，确认后继续
  - Android：暂停，请用户在设备上手动登录，用户确认"已登录"后继续
- 不读取、不记录、不传输控件树中 `password="true"` 节点的文本

## 3. 权限处理

| 权限 | 策略 |
|---|---|
| 通知、定位（粗略）、相机（预览页）、麦克风（预览） | 可自动允许（`pm grant` 或点"允许"），并在汇报中列出 |
| 通讯录、相册/存储、短信、通话记录、精确位置 | **暂停询问用户**，用户同意后 `adb shell pm grant <包> <权限>` |
| 无障碍服务、设备管理器、安装未知应用 | 永不自动授予，只提示用户 |

自动允许后若出现二次确认弹窗（"始终允许/仅使用期间"），选"仅使用期间允许"。

## 4. 验证码与风控

- 滑块/图形/短信验证码：暂停，交给用户手动完成
- 触发风控（频繁操作提示/账号风险提示）：立即停止本次捕获，告知用户，建议改天用更小预算重试
- 动作间加随机延时（0.8-2s），避免机器节奏

## 5. 预算与中断

- 全量遍历必须先设预算（屏数/步数），到达预算停下来汇报，**不擅自加预算**
- 用户随时可以说"停"，立即停止操作（保留已捕获产物）
- 捕获前关闭与应用无关的干扰：勿扰模式建议开启（仅建议，不代操作）

## 6. 内容合规

- 捕获的截图/视频版权归原作者与平台；产物目录不上传、不公开分享
- 交付时提醒用户：**复刻原型仅限个人学习/内部参考，不得冒充原创发布，不得商用**
- 不克隆涉及违法内容的应用；遇到成人/赌博类内容立即终止并说明

## 7. 设备安全

- 不在捕获过程中卸载应用、清除应用数据、修改系统设置（除用户明确要求）
- 录屏文件可能包含用户隐私（通知栏/头像），交付时提醒用户检查 videos/ 目录
- 使用用户设备前确认目标应用已登录的是**用户自己的账号**，避免误操作他人账号

## 8. 暂停话术模板

```
⏸ 已到达安全边界：<原因，如"支付确认页">
已捕获：<n> 屏 / 录屏 <路径>
这条路径到此为止。你可以：
1) 继续其他路径  2) 到此为止，开始生成原型  3) 你手动操作后告诉我继续
```

## 9. 系统改动的恢复义务

捕获过程对设备/系统做的任何改动，**结束时必须恢复**（跑 `scripts/android/prepare.sh --restore`）：

- `svc power stayon usb`、`screen_off_timeout` 加大 → 还原原值
- 用户临时关的锁屏密码、开的勿扰/无线调试 → 提醒恢复（不代操作）
- Mac 端 `caffeinate` → kill
- 恢复清单在交付时一并告知用户；未恢复不得结束会话

## 10. 本地写入口（M11）
- serve.mjs `/__dc_write__` 仅 loopback（127.0.0.1/::1）+ 白名单：
  prototype/{edit-overrides,layout-overrides,annotations,products,paths}.json，其余一律 400
- `/__dc_export__` 同 loopback 守卫；headless 截屏只访问自身 localhost 服务，不外联

## 10. 隐私分层（M17）

复刻产物的隐私四防线（细节见 completeness-protocol §9）：
1. capture 原图仅本机；2. pixel 资产必 mask（img/mask.mjs + privacy-rects.json）；
3. 文本全虚构 + privacy-scan 清零；4. handoff 声明匿名化。
3b. 视觉资产（M19）：所有者 run 默认**真视觉+文本匿名**（头像/配图/图标用 capture 真图且过 asset-qa；昵称/ID/聊天文字仍虚构或打码）；他人/第三方 run 用真视觉资产前必须询问授权；用户选虚构人脸时 genimg 替代。
群设置/好友设置/联系人卡片等含联系人真实信息页：允许捕获（用户授权），
但**截屏后立即生成 mask 版资产**，views 只引用 mask 版。

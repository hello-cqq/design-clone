# 风格提取（style_only 分支）

> 有的图/视频不是产品 UI，而是"有审美的素材"（摄影/插画/动效/海报）。
> 此分支不复刻界面，只提取**设计风格**，再结合用户诉求生成原型（intent=style_only 时走这里）。

## 流程

1. **取证**：正常走梯级拿帧/图（L1-L4），或用户直接给本地图/视频
2. **tokens 量化**：`node tokens.mjs <帧目录> --out knowledge/`（主色/背景/圆角）
3. **VLM 气质分析**（宿主读 3-6 张关键帧，按下面提示词）：
   ```
   看这组素材，输出设计风格简报：①情绪关键词3个 ②色彩性格（饱和/对比/温度）
   ③字体气质（衬线/圆体/等宽/手写）④构图习惯（留白/满版/网格）⑤动效暗示（缓/弹/闪切）
   ⑥可迁移到 UI 的 3 条具体规则（如"大圆角+奶油底+高饱和四色"）。不要泛泛而谈。
   ```
4. **落盘**：`knowledge/style-brief.md`（上述六项）+ `knowledge/tokens.css`（量化值+agent 校准）
5. **生成**：按用户诉求（"做个记账 app 首页"）用该风格生成原型——走 prototype-spec，
   `design_system_ref` 指向本目录；若用户同时要界面复刻，先 product_ui 后 Remix 换风格

## 与预设库的关系

style-brief 产出即一个**新预设**：登记进 `presets/index.md`，命名 `<来源平台>-<主题>`，
之后任何原型的 Remix 都可引用（"用那个海獭风改这版"）。

## 边界

- 风格可借鉴，**具体插画/IP 形象不照抄**（版权）：用 blob/几何占位传达气质
- 素材含品牌 logo 时只记录"存在强 IP"这一事实，不复制 logo

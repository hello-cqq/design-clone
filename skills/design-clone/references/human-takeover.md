# 人接管协议（human-takeover）

自动化卡住时，不猜、不硬重试超过 2 次，按本协议把用户拉进来。
每个卡点四段式：**检测 → 引导话术 → 恢复验证 → 继续**。

## 0. 总则

- 引导话术直接可复制给用户，含「手机侧/电脑侧」明确分边
- 用户操作完成后必须跑「恢复验证」命令确认，再恢复自动化
- 涉及隐私/安全的项（解锁、登录、关锁屏、安全开关）只引导，不代操作，不绕过
- 同一卡点两次引导仍未解决 → 停止本次捕获，保留产物，给出排查清单（install-guide.md）

## 1. 连接类

### 1.1 无设备（adb devices 空）
检测：`adb devices` 无 `device` 行。
引导：
```
📱 没检测到手机，请逐项检查：
1) 数据线是否传数据（换原装线/换个 USB 口，很多线只充电）
2) 手机：设置→关于手机→连点"版本号"7 次开启开发者模式
3) 开发者选项里打开「USB 调试」
4) 重新插拔，手机会弹「允许 USB 调试？」→ 勾选"一律允许"→ 确定
完成后告诉我，我继续。
```
验证：`adb devices` 出现 `<序列号>  device`。

### 1.2 unauthorized
检测：状态列 = `unauthorized`。
引导：看手机是否有授权弹窗（可能被折叠通知挡住）；没有就拔线重插；
仍不行：开发者选项→「撤销 USB 调试授权」→ 重插重新授权。
验证同上。

### 1.3 offline / 权限不足（Linux）
检测：`offline` 或 `no permissions`。
引导：Linux 加 udev 规则（见 install-guide.md）；重插；或换无线调试。
验证同上。

## 2. 注入类（tap/swipe 无效）

检测：连续 2 次动作后截图感知哈希不变，且 keyevent（如 BACK）有效或无效分两种：
- keyevent 也无效 → 注入整体被拦：
  - 小米/红米：开发者选项开「USB 调试（安全设置）」（需登录小米账号+等 10 分钟冷却，提示用户耐心）
  - OPPO/vivo/华为：类似「禁止权限监控/允许通过 USB 安装应用/允许模拟点击」开关，按品牌提示
  - 引导话术：
    ```
    ⚙️ 点击注入被系统拦截（<品牌> 安全策略）。请在手机开发者选项打开：
    「USB 调试（安全设置）」/「允许模拟点击」（不同品牌名称略异）
    打开过程可能需要登录账号并等待几分钟冷却。好了告诉我。
    ```
- keyevent 有效、tap 无效 → 坐标问题：重新 dump 控件树用 bounds 中心，勿用视觉估计。
验证：在已知界面 `input tap` 一个安全目标（如下拉通知再收起）看哈希变化。

## 3. 屏幕/电源类

### 3.1 灭屏
检测：`adb shell dumpsys power | grep mWakefulness` = `Asleep`，或截图为锁屏/AOD。
自动：`adb shell input keyevent 224`（唤醒）。
若唤醒后是锁屏 → 解锁必须用户：
```
🔒 手机锁屏了。请解锁（密码/人脸不经过我），或捕获期间临时取消锁屏：
设置→密码与安全→关闭锁屏密码（结束我会提醒你恢复）。
```
预防：捕获前跑 `scripts/android/prepare.sh`（stayon + 长超时）。

### 3.2 电脑睡眠（mac）
长捕获前提示/执行 `caffeinate -i &`；结束 kill。

### 3.3 通知打扰
建议用户开勿扰（不代开）：「捕获约 N 分钟，建议开勿扰，避免通知挡住界面/进录屏」。

## 4. 账号/凭证类
登录、验证码、支付密码、人脸：一律暂停+话术（见 safety-rules.md 模板），
补充通用句式：「这一步需要你本人在<手机/浏览器窗口>完成，我在旁边等，完成后回复『继续』」。

## 5. 电脑侧权限（mac 桌面/iOS 镜像模式）
检测：截屏全黑 / 点击无响应。
引导：系统设置→隐私与安全性→「辅助功能」与「屏幕录制」→ 勾选当前终端/IDE → 可能需要重启终端。
验证：`screencapture -x /tmp/t.png && file /tmp/t.png` 非全黑。

## 6. 安装类
doctor 输出 `[需要安装]` 时：按 install-guide.md 给当前平台命令；
用户无 brew/winget 权限等 → 给替代方案（官方 zip 解压+PATH）。

## 7. 结束恢复义务（捕获完成必做）
跑 `scripts/android/prepare.sh --restore`，并提醒用户：
- 恢复锁屏密码（若临时关闭）
- 关闭无线调试（若启用）
- 录屏/截图含隐私，检查 capture/ 目录再分享

# VISION — 诉求与产品定位（用户原始需求的完整记录与演进）

> 本文件是"为什么做、做成什么"的唯一权威。任何实现偏离时回到这里对齐。

## 0. 一句话定位（最新）

**design-clone：以克隆为起点，产出可用于生产的"活 PRD"** ——
可交互原型 + 产品批注 + 设计 inspect + 功能路径故事板/播放 + 可编辑 + 可导出，
让没有设计经验的创作者/开发者站在优秀产品肩膀上起步。

## 1. 原始诉求（逐条追溯）

1. **跨 agent 通用 skill**：opencode / Codex / Claude Code / WorkBuddy / 豆包(Trae) / 千问(Qwen Code) / Qoder 均可用
2. **自动捕获真实应用**：Android/iOS/mac/Windows/网页、手机/平板/电脑；模拟人交互
   （滑动/点击/长按/下拉/页面切换/拖拽）；全流程录屏；权限能引导授予；截图与视频按
   产品设计语义结构化（原子功能场景/大场景）
3. **一比一复刻为可交互原型**：本地 Web 应用，浏览器直接交互；接入 Figma MCP 时还能出高保真设计稿
4. **场景级克隆**：不只能全量，还能"只要微信支付场景这条路径"
5. **零额外消费**：除用户已有大模型 API 外不花钱；效果要好
6. **链接取材**：抖音/B站/小红书等视频/图文链接（或本地视频图片），agent 能"像人一样看"，
   提取全部有效信息复刻原型
7. **Remix**：复刻为主、用户想法为辅——按 prompt 改字体/颜色/风格/动效/交互/视觉，增量生成新原型
8. **Inspector（后补诉求）**：原型内置模式切换——
   - 普通视角：纯净原型
   - 产品视角：折线批注元素的功能与交互事件（点击/长按/开关→各自响应），像产品设计稿
   - 设计视角：Figma 式 inspect，每个元素/图层的颜色/字体/分辨率
   - 编辑模式 + 拖拽 + 缩放
   - **完整功能路径展示**：点某菜单→下级页展示什么→再操作弹出什么弹窗；
     诉求原话："skill 最终能真正实现一个可用于生产的产品原型设计，已经不再是一个简单的设计克隆"

## 2. 硬约束

- 除大模型 API 外零额外消费（全部开源免费工具；本地模型仅作为有 GPU 用户的可选项）
- 安全红线：支付确认不点、凭证不输、验证码/登录交给人、隐私数据匿名化、系统改动要恢复
- 跨端可移植：SKILL.md 只用 Agent Skills 规范 6 字段，脚本裸 bash 可跑、不绑 MCP

## 3. 范围决策记录（用户当面确认）

- MVP 平台：Web + Android 先行；iOS 模拟器优先、真机引导配置；桌面靠后
- 决策大脑：宿主 agent VLM 默认；MAI-UI-2B/GUI-Owl 本地增强可选
- 原型形态：静态 HTML + 自带组件库 + tokens.css；utility 子集由 gen/utility-css.mjs 本地编译（M45 起无运行时 CDN，离线/file:// 可开）
- 编辑模式深度（本轮）：拖拽 + 导出 layout-patch，实时写回 spec 留后续
- 路径展示 v1：故事板抽屉 + 原型内播放；自动流程图 v2
- 实施顺序：Inspector 先于 M2 链接模式

Guide

Three moves: install → clone → publish. Everything else is gated for you.

1 · INSTALL

One command

Paste the installer for your agent (opencode / claude / codex) or use npx skills add hello-cqq/design-clone -g. See Install.

2 · CLONE

Ask your agent

“Use design-clone to clone <app or url>.” The skill captures, rebuilds a playable prototype, runs its gates, and serves it locally.

3 · PUBLISH

Share to the gallery

node <skill>/scripts/publish.mjs --run <run> --app <app> --title "…" [--title-zh --desc --desc-zh --tags --version] opens a PR to design-clone-prototype; after review it goes live here with your avatar on it. Generation already emits the gallery trio (meta.json bilingual + icon.png + 3:2 cover.png) and design specs (pages/*.spec.json, design/figma-source.json) — publish carries them; gates must be green first.

发布一行命令：publish.mjs --run <run> --app <app> --title "…"（中英描述/标签/版本可覆盖）。生成期已产画廊三件套（双语 meta.json + icon.png + 3:2 cover.png）与设计规格（pages/*.spec.json、design/figma-source.json），publish 自动搬运；三门绿+gallery-ready 才放行，PR 经维护者审核后上线并署贡献者头像。

Submission spec, in one breath

Full text: SPEC.md (中文)

Layout

app/flavor/prototype/; flavor vocabulary mobile|tablet|desktop|web + optional platform + -cn|-global.

Gates first

interact dead=0 · inspect 0 fail · ui-smoke 0 fail · privacy green. CI re-smokes every PR.

Privacy & IP

No real personal data, ever. Three-way IP attestation; brand clones carry a disclaimer.

Versions

SemVer per flavor; bump on any prototype/** change; merges auto-tag app-flavor-version with an offline zip Release.

Size

≤80 MB per flavor; system fonts; no runtime CDN — prototypes must work fully offline.

Review

No auto-merge. A maintainer approves every prototype; takedown issues answered within 48 h.

FAQ

Do prototypes need a server?

No. They are offline static bundles; GitHub Pages serves them as live apps (annotation writes fall back to localStorage).

Can I remix someone's prototype?

Yes — clone the flavor directory, remix in the skill, publish your own flavor or app with attribution in PROVENANCE.md.

Which license?

Prototype code MIT; assets per flavor license (default CC-BY-4.0); repo infrastructure MIT.

Guide
1 · INSTALL

One command

Paste the installer for your agent (opencode / claude / codex) or use npx skills add hello-cqq/design-clone -g. See Install.

2 · CLONE

Ask your agent

“Use design-clone to clone <app or url>.” The skill captures, rebuilds a playable prototype, runs its gates, and serves it locally.

3 · PUBLISH

Share to the gallery

node <skill>/scripts/publish.mjs --run <run> --app <app> --title "…" [--title-zh --desc --desc-zh --tags --version] opens a PR to design-clone-prototype; after review it goes live here with your avatar on it.

发布一行命令：publish.mjs --run <run> --app <app> --title "…"。生成期已产画廊三件套（双语 meta.json + icon.png + 3:2 cover.png）与设计规格，publish 自动搬运；三门绿+gallery-ready 才放行，PR 经维护者审核后上线并署贡献者头像。

Gates first

interact dead=0 · inspect 0 fail · ui-smoke 0 fail · privacy green. CI re-smokes every PR.

Privacy & IP

No real personal data, ever. Three-way IP attestation; brand clones carry a disclaimer.

Offline bundles

Prototypes are static bundles; GitHub Pages serves them as live apps; no runtime CDN.

Install in one command

Pick your agent — the command installs the skill globally plus its gate dependencies (Node ≥20.19, Playwright Chromium). Re-run anytime to update.

Fast channel

Add -- --skip-deps for a seconds-fast install; the skill's doctor will guide dependency install on first gate run.

Pinned / snapshot

-- --ref v0.6.0 pins a release; -- --channel snapshot tracks prerelease snapshots.

No CLI / air-gapped

Grab the zip from Releases and unpack into your agent's skills directory.

First sentence after install — open your agent and say: “Use design-clone to clone <your app or url>.”

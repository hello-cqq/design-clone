What the skill does

Five capabilities, one workflow, gated end-to-end.

CAPTURE

Capture anything

Android via adb/scrcpy, web via crawl, video/link frames — with UI trees, tokens, and journey graphs.

REBUILD

Rebuild playable

Static HTML prototypes with an inspector shell: scene tree, path mode, play, compare, annotations.

ARTIFACTS

Design artifacts

Per-page product spec JSON + Figma-source (variables, frames, nodes) generated at build time, re-exported after edits.

GATES

Gated quality

Dead-control, parity, privacy, typography, and paste-screenshot gates — red means not shippable.

PUBLISH

Publish & remix

One command opens a PR to the community gallery; every prototype stays remixable.

ZERO SERVER

Zero server

Prototypes are fully offline static bundles — GitHub Pages hosts them as live apps.
